# Health View — Landing Page para Profissionais (V6)

Versão com posicionamento comercial em 5 dimensões de gestão, design editorial e sem preços públicos.

## Estrutura
- `index.html` — landing principal
- `obrigado.html` — página de conversão
- `privacidade.html` — política de privacidade
- `assets/css/` — estilos separados
- `assets/js/` — configuração, tracking e comportamento
- `assets/img/` — imagens
- `assets/docs/` — apresentação comercial
- `SEO-CAMPANHAS.md` — grupos de palavras-chave, UTMs e conversões

## Configuração
Edite `assets/js/config.js`:
- número do WhatsApp
- endpoint do formulário
- GTM/GA4/Google Ads/Meta (conforme sua implementação)

Atualize em `index.html`, `sitemap.xml`, `robots.txt` e páginas auxiliares:
- `SEU-DOMINIO.com.br`

## Publicação no Git
Publique o conteúdo desta pasta na raiz do projeto/site. Não é necessário framework ou processo de build.
